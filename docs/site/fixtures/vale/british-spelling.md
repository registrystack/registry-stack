# British spelling fixture

The organization will normalize the color of each catalog. The behavior of the programme is unchanged.

Standards and identifiers keep their own spelling. The Authorization header carries the token. The authorization server issues an authorization_code. See `normalize_color` and the path /etc/catalog/color.json. The International Organization for Standardization publishes the Apache License.
