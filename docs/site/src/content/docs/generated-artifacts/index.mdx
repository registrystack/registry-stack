Generated files name their source or generator in a header, adjacent manifest, or owning product
documentation. Change the source and rerun the documented generator. Do not hand-edit generated
OpenAPI, command reference, schema, or publication output.

Static Registry Manifest output is a publication artifact. Evidence Gateway generated contracts are
owned by its contract generator. The documentation site's generated product and command references
are rebuilt by the scripts documented in the site README.
