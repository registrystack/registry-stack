Registryctl writes generated material under `.registry-stack/` and into an
explicit deployment package.
These outputs show what Registry Stack derived from authored intent; they are
not another configuration surface.

## Keep one source of truth

Edit the project, integration, entity, fixture, and environment files.
Then rerun the Registryctl command that owns the generated output.
Never repair a result by editing generated product configuration.

## Build output

| Path | Purpose | Ownership |
| --- | --- | --- |
| `.registry-stack/build/<environment>/artifact-manifest.json` | Hashes the authored inputs and generated closure | Registryctl generates; reviewer retains |
| `.registry-stack/build/<environment>/reviewable/` | Value-free material for human review | Registryctl generates; reviewer inspects |
| `.registry-stack/build/<environment>/signing-inputs/relay-public/` | Unsigned public Relay lane | Registryctl generates; Relay signer approves |
| `.registry-stack/build/<environment>/signing-inputs/relay-consultation/` | Unsigned consultation Relay lane | Registryctl generates; Relay signer approves |

The two signing inputs stay independent.
An approved baseline set locates their signed bundles and anchors, but does not
become another signature or activation authority.

## Development output

`.registry-stack/dev/` contains the bound disposable environment, local state,
and runtime observations.
`.registry-stack/dev-artifacts/` contains generated local trust and product
inputs.

Registryctl may rebuild or remove both locations.
Keep them private and separate from governed environments.

## Deployment output

`registryctl deploy generate` writes a portable package into the exact
`--output-dir` selected by the operator.
The package contains a normalized approved-set copy, immutable product inputs,
operator bindings, a platform-neutral deployment plan, generated Compose
material, and a runbook.

Registryctl owns the managed closure.
The operator owns binding values, secret values, certificates, durable state,
and declared adaptations.
Generation never activates the package.
