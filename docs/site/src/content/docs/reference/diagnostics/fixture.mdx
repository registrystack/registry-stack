Use this catalog for the safe error codes produced by Registryctl's offline synthetic fixture
harness. These entries describe bounded fixture evidence. They do not prove that a live source is
reachable, compatible, or authorized.

Run `registryctl project diagnostics --catalog fixture --format json` for the exact
workspace-independent machine catalog. The command does not open a country project, contact a
runtime, or read environment variables and secrets.
