Registry Stack HTTP products own their error contracts. Use the product reference that matches the
service you call instead of assuming codes or response shapes carry across products.

## Evidence Gateway

[Evidence Gateway problem types](../evidence-problems/) is the maintained reference for the
Gateway's closed problem set. The runtime-owned generator reproduces its committed schema and
OpenAPI artifacts under CI.

## Evidence OID4VCI supporting service

The OID4VCI delivery service has its own protocol error vocabulary in the
[committed OpenAPI artifact](https://github.com/registrystack/registry-stack/blob/main/products/evidence/generated/registry-evidence-oid4vci.openapi.json).
Framework-level refusals that never enter the protocol handler can intentionally use `text/plain`.

## Retired Relay codes

Registry Relay and its problem-code catalog were retired in Registry Stack 0.39.0. Existing
integrations can use the immutable 0.38.0 documentation while planning a replacement. See the
[Relay retirement decision](../../decisions/registry-relay-retirement-2026-10-03/).
