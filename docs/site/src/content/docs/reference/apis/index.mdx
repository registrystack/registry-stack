Maintained products publish their API contracts in the owning product section. Base Registry
Engine (BReg) publishes its contract with its product reference.

## Fixed generated APIs

The documentation build renders committed OpenAPI contracts for Registry Evidence, Registry
Casework, Registry Scheduling, and Registry Messaging when the selected docset contains those
products, and the wallet-facing OID4VCI delivery contract of the supporting service beside
Registry Evidence. Generated operation pages inherit the source contract and must not be edited by
hand.

<DocsetProduct product="registry-coordinator">

</DocsetProduct>

<DocsetProduct product="registry-documents">

The build also renders the committed OpenAPI contract for the Registry Document Store.

</DocsetProduct>

Base Registry Engine publishes its maintained API contract in the
[BReg API reference](../breg-api/). Registry Render documents its input and service modes in its
product guide.

## Contract ownership

Each product owns its routes, authentication, request and response schemas, problem types, and
compatibility policy. A client must use the reference for the product it calls.
