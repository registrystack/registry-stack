Use the [Standard Webhooks specification](https://github.com/standard-webhooks/standard-webhooks/blob/4a8ee40c5bcb6157f856905cc8871040d41a78ce/spec/standard-webhooks.md)
to authenticate deliveries before your receiver acts on them.

## What every product sends

This contract applies to these senders:

- [Base Registry Engine](../../operate/breg-webhooks/) event destinations and proposal hooks.
- [Registry Document Store](../../security/documents/) hooks.
- [Registry Scheduling](../../security/scheduling/) hooks and reminders.
- [Registry Adapter](../../operate/adapter/) jobs that send signed Coordinator events.
- [Registry Casework](../../security/casework/) completion wakes.

| Request part | Value |
| --- | --- |
| Method | `POST` |
| `content-type` | `application/json` |
| `webhook-id` | The event ID in the body, reused on every retry and operator replay |
| `webhook-timestamp` | The attempt time in Unix seconds |
| `webhook-signature` | `v1,<base64>` entries separated by one space, current key first, with two entries while a previous key is configured |

The sender joins `webhook-id`, a period, `webhook-timestamp`, a period, and the exact body bytes.
It signs those bytes with HMAC-SHA-256 and encodes the result in standard base64 with padding.

Casework completion wakes add the unsigned `registry-recipient-binding` header.
Use it to select the receiver key. Each connection uses a distinct key, so a changed binding fails
verification.
See [Casework completion receivers](../../configure/casework-completion-receivers/).

## The key

Every product reads the key file as 32 to 64 exact bytes, without trimming or base64 decoding.
Generate a file with 64 hexadecimal characters:

```sh
openssl rand -hex 32 | tr -d '\n' > webhook.key
```

Plain `openssl rand -hex 32 > webhook.key` writes 65 bytes: 64 hexadecimal characters and a newline.
The sender refuses that length at startup and names the trailing newline.
A file within the length limit may end in a newline.
Use the same file on the receiver because the newline is part of the key.
Products refuse key files that start with `whsec_`.

Set the current key file with `hmacSha256KeyRef` and the optional previous file with
`previousHmacSha256KeyRef`. Use a different key for each destination.
If two destinations share key bytes, the sender refuses to start and names both settings.

{/* Evidence: crates/registry-platform-crypto/src/delivery_signature.rs DeliveryKey, distinct_delivery_keys(). */}

## Verify, in five steps

1. Require exactly one value each for `webhook-id`, `webhook-timestamp`, and `webhook-signature`.
2. Require a canonical decimal timestamp within the [delivery window](#the-window-and-clocks).
3. Verify the signature over the raw body bytes before parsing. Compare the signature in constant
   time.
4. Parse the authenticated body.
5. Require `webhook-id` to equal `id` in a registry event envelope or `eventId` in a Casework
   completion wake.

## The window and clocks

Accept timestamps up to 300 seconds before or after your receiver clock.
Keep your receiver clock synchronised.
Base Registry Engine, Document Store, and Scheduling stamp each attempt when they take its lease.
Adapter and Casework stamp each attempt when they send it.
Coordinator, Base Registry Engine, and the client helpers apply the same window.

## Duplicates

Retries and operator replays reuse `webhook-id`.
Before acting, store the authenticated sender identity and `webhook-id` with a digest of the body.
Refuse a different body under a stored ID.
Keep the IDs for at least the sender's retry span, which can exceed the verification window.
By default, Casework allows 12 completion wake attempts 30 seconds apart.
You can configure up to 100 attempts with up to 86,400 seconds between them.

You can skip the store when acting twice is harmless, for example when a wake only prompts you to
read an authoritative result.
Without a store, the timestamp window bounds how long someone can replay a captured delivery.

## Rotation, three restarts, no missed delivery

1. On the sender, copy the current key file to `<name>.previous`.
   Set `previousHmacSha256KeyRef` to the copy, write new bytes to the original file, and restart
   the sender.
   It signs with both keys, current first, and re-signs retained retries at send time.
2. On the receiver, copy the current key file to `<name>.previous` and configure it as the
   previous key.
   Write the same new bytes to the original file and restart the receiver so it accepts either key.
3. Remove `previousHmacSha256KeyRef` and restart the sender.
   Then remove the previous key from your receiver configuration so the receiver uses only the
   current key.

Keep the path in `hmacSha256KeyRef` throughout rotation.
The sender refuses to start if the previous and current keys contain the same bytes.

## Helpers

Use these helpers for registry event envelopes. Use the Casework completion receiver contract for
completion wakes.

- Rust runs `registry_stack_client::breg::verify_hook_delivery`.
- Node runs `breg.verifyHookDelivery`.
- Python runs `breg.verify_hook_delivery`.

Each takes the headers, raw body bytes, key, and optional previous key.
It returns the ID, timestamp, source, type, time, dataschema, and body.
See [Verify a hook delivery](../client-api/#verify-a-hook-delivery).

The Standard Webhooks Python library's `Webhook` constructor uses a `bytes` key as supplied.
It base64-decodes a `str` secret after removing an optional `whsec_` prefix.
For a library that only accepts a text secret, use `whsec_` followed by the standard base64 of the
exact key bytes.
Check the library's documentation for a raw-key entry point.

## Example receiver in Go

In the [Go receiver example](https://github.com/registrystack/registry-stack/tree/main/products/platform/examples/delivery-receiver-go),
`main.go` serves `/events` on loopback and keeps seen IDs in memory for ten minutes only.
For a production receiver, keep the IDs durably for the sender's retry span.

```go
package main

import (
    "bytes"
    "crypto/hmac"
    "crypto/sha256"
    "encoding/base64"
    "math"
    "strconv"
    "strings"
    "time"
)

type Refusal string

func (r Refusal) Error() string { return string(r) }

const (
    InvalidKey          Refusal = "invalid-key"
    InvalidID           Refusal = "invalid-id"
    BodyTooLarge        Refusal = "body-too-large"
    InvalidTimestamp    Refusal = "invalid-timestamp"
    MalformedSignature  Refusal = "malformed-signature"
    UnsupportedVersion  Refusal = "unsupported-version"
    SignatureMismatch   Refusal = "signature-mismatch"
    StaleDelivery       Refusal = "stale-delivery"
    maxBodyBytes                = 1 << 20
    maxSignatureEntries         = 4
    deliveryTolerance           = 300 * time.Second
)

func Verify(keys [][]byte, id, timestamp, signature string, body []byte, now time.Time) error {
    if len(keys) < 1 || len(keys) > 2 {
        return InvalidKey
    }
    for _, key := range keys {
        if len(key) < 32 || len(key) > 64 || bytes.HasPrefix(key, []byte("whsec_")) {
            return InvalidKey
        }
    }
    if len(keys) == 2 && bytes.Equal(keys[0], keys[1]) {
        return InvalidKey
    }

    if len(id) == 0 || len(id) > 256 {
        return InvalidID
    }
    for i := 0; i < len(id); i++ {
        if id[i] < '!' || id[i] > '~' || id[i] == '.' {
            return InvalidID
        }
    }
    if len(body) > maxBodyBytes {
        return BodyTooLarge
    }

    if len(timestamp) == 0 || len(timestamp) > 20 || (len(timestamp) > 1 && timestamp[0] == '0') {
        return InvalidTimestamp
    }
    for i := 0; i < len(timestamp); i++ {
        if timestamp[i] < '0' || timestamp[i] > '9' {
            return InvalidTimestamp
        }
    }
    seconds, err := strconv.ParseUint(timestamp, 10, 64)
    if err != nil {
        return InvalidTimestamp
    }

    tags, err := signatureTags(signature)
    if err != nil {
        return err
    }
    for _, key := range keys {
        mac := hmac.New(sha256.New, key)
        mac.Write([]byte(id + "." + timestamp + "."))
        mac.Write(body)
        expected := mac.Sum(nil)
        for _, tag := range tags {
            if hmac.Equal(expected, tag) {
                if seconds > math.MaxInt64 {
                    return StaleDelivery
                }
                // Bias signed Unix seconds so unsigned subtraction preserves their order.
                delivery := seconds + 1<<63
                receiver := uint64(now.Unix()) ^ (1 << 63)
                if delivery > receiver {
                    if delivery-receiver > uint64(deliveryTolerance/time.Second) {
                        return StaleDelivery
                    }
                } else if receiver-delivery > uint64(deliveryTolerance/time.Second) ||
                    (receiver-delivery == uint64(deliveryTolerance/time.Second) && now.Nanosecond() != 0) {
                    return StaleDelivery
                }
                return nil
            }
        }
    }
    return SignatureMismatch
}

func signatureTags(signature string) ([][]byte, error) {
    entries := strings.SplitN(signature, " ", maxSignatureEntries+1)
    if len(entries) > maxSignatureEntries {
        return nil, MalformedSignature
    }
    var tags [][]byte
    for _, entry := range entries {
        version, value, found := strings.Cut(entry, ",")
        if !found || version == "" || value == "" {
            return nil, MalformedSignature
        }
        if version != "v1" {
            continue
        }
        if len(value) != base64.StdEncoding.EncodedLen(sha256.Size) {
            return nil, MalformedSignature
        }
        tag, err := base64.StdEncoding.Strict().DecodeString(value)
        if err != nil || len(tag) != sha256.Size {
            return nil, MalformedSignature
        }
        tags = append(tags, tag)
    }
    if len(tags) == 0 {
        return nil, UnsupportedVersion
    }
    return tags, nil
}
```
