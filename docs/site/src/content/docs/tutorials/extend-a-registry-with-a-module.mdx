In about fifteen minutes you will add an optional internal note to every contact without editing
the contact Record type itself: the module written, pinned, checked for production, and visible in
the generated schema.

<QuickstartMeta
  outcome="The contact Record type extended by a pinned module that passes the production check and appears in the generated schema."
  time="About 15 minutes"
  level="Local evaluation only"
  prerequisites={['The project from Change a registry with an Action, with its registry running', 'An editor']}
/>

## Write the module

A [module](../../reference/glossary/#module) is a separate file of additions to a project. In the
project directory, create its folder:

```sh test-cwd="tutorial-work/project"
mkdir -p modules/contact-notes
```

Create `modules/contact-notes/module.yaml`:

```yaml title="modules/contact-notes/module.yaml" test-file
apiVersion: id.registrystack.org/formats/breg/module/v1alpha1
kind: BRegModule
id: contact-notes
version: 0.1.0
extendRecordTypes:
  - recordType: contact
    fields:
      - id: internal-note
        type: text
        required: false
        maximumLength: 2000
        classification: internal
```

Add the module to `registry.yaml`, before `datasets`:

```diff lang="yaml" title="registry.yaml" test-edit
-datasets:
+modules:
+  - id: contact-notes
+    version: 0.1.0
+
+datasets:
```

## Let the editor read and write the note

A new field is hidden from every caller until an access profile names it. Add it to the editor's
fields:

```diff lang="yaml" title="registry.yaml" test-edit
-          readableFields: [name, email, jurisdiction]
-          writableFields: [name, email, jurisdiction]
+          readableFields: [name, email, jurisdiction, internal-note]
+          writableFields: [name, email, jurisdiction, internal-note]
```

Who may read a contact is unchanged.

## Pin the module and check

```sh
rstack breg project lock .
```

```text test-expect
Locked the project modules. 1 artifact written.
  revision  sha256:<digest>

  registry.yaml

{
  "changed": true,
  "modules": [
    {
      "digest": "sha256:<digest>",
      "id": "contact-notes",
      "status": "updated",
      "version": "0.1.0"
    }
  ]
}
```

The lock writes the digest of the module's exact bytes into `registry.yaml`. If the module file
changes later, the check fails until you lock again.

```sh
rstack breg check . --production
```

```text test-expect
Production check passed; registry revision sha256:<digest>.
0 errors, 0 warnings in 4 files
```

## Generate the contact schema

```sh
rstack breg generate schemas . --output ../contact-schemas
```

```text test-expect
Generated 9 artifacts.
  revision  sha256:<digest>

  generated/action-schemas/register-contact.invoke.input.schema.json
  generated/action-schemas/register-contact.invoke.response.schema.json
  generated/action-schemas/update-contact-email.availability.input.schema.json
  generated/action-schemas/update-contact-email.availability.response.schema.json
  generated/action-schemas/update-contact-email.invoke.input.schema.json
  generated/action-schemas/update-contact-email.invoke.response.schema.json
  generated/action-schemas/update-contact-email.target-conditions.input.schema.json
  generated/action-schemas/update-contact-email.target-conditions.response.schema.json
  generated/schemas/contact.schema.json
```

These JSON Schemas describe what the API accepts and returns. In
`../contact-schemas/generated/schemas/contact.schema.json`, the note appears as `internalNote`: a
string of at most 2000 characters, or null, and not in the `required` list.

```json title="contact.schema.json" test-excerpt="../contact-schemas/generated/schemas/contact.schema.json"
{
  "internalNote": {
    "anyOf": [
      {
        "maxLength": 2000,
        "type": "string"
      },
      {
        "type": "null"
      }
    ]
  }
}
```

## Stop the registry

The running registry was built from the project as it was, and its test data was written for that
version. Stop it and discard that data:

```sh
rstack breg dev stop --remove
```

```text test-excerpt
bregctl dev succeeded.
  status          stopped
```

Keep the project: the next `rstack breg dev start` in this directory runs it with the note.
