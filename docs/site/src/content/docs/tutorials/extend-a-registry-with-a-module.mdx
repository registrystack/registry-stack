If you completed the first Base Registry Engine (BReg) tutorial, add an optional contact note through a
module, grant it explicitly, and pin the module's exact bytes before generating
the updated schema. This exercise changes files without starting a registry.

<QuickstartMeta
  outcome="A native module extending the contact Record type, with explicit field grants and a content lock."
  time="About 15 minutes"
  level="Offline authoring"
  prerequisites={['The tutorial-work/project directory from the first BReg tutorial', 'Matching bregctl binary', 'An editor']}
/>

## Add a module

```sh
mkdir -p tutorial-work/project/modules/contact-notes
```

Create `tutorial-work/project/modules/contact-notes/module.yaml` with this content:

```yaml title="tutorial-work/project/modules/contact-notes/module.yaml" test-file
apiVersion: id.registrystack.org/formats/breg/module/v1alpha1
kind: BRegModule
id: contact-notes
version: 0.1.0
extendRecordTypes:
  - recordType: contact
    fields:
      - id: internal-note
        type: text
        required: false
        maximumLength: 2000
        classification: internal
```

Register the module in `tutorial-work/project/registry.yaml`, before `datasets`:

```diff lang="yaml" title="tutorial-work/project/registry.yaml" test-edit
-datasets:
+modules:
+  - id: contact-notes
+    version: 0.1.0
+
+datasets:
```

## Grant the field explicitly

Adding a field grants no disclosure or write authority. Add it to the editor's
record permission:

```diff lang="yaml" title="tutorial-work/project/registry.yaml" test-edit
-          readableFields: [name, email, jurisdiction]
-          writableFields: [name, email, jurisdiction]
+          readableFields: [name, email, jurisdiction, internal-note]
+          writableFields: [name, email, jurisdiction, internal-note]
```

The jurisdiction boundary is unchanged. The note receives no filter, sort, or
other profile grant.

## Pin and check the source

```sh
bregctl project lock tutorial-work/project
bregctl check tutorial-work/project --production
```

Inspect `registry.yaml` for the module digest. The lock binds its version and exact
source bytes. A later module edit requires another deliberate lock and check;
changing generated output cannot repair a source mismatch. Read a diagnostic's
named file and member if the check refuses.

## Generate the field contract

```sh
bregctl generate schemas tutorial-work/project --output tutorial-work/contact-schemas
```

Open `tutorial-work/contact-schemas/generated/schemas/contact.schema.json`.
The optional note uses its generated API name `internalNote` and maximum length.
The existing required contact fields remain required. Generation needs a fresh
output path; choose another path for the next candidate.

No database changed. Activating a successor over retained records requires the
normal test, package, and operator lifecycle. The first tutorial's disposable
session remains stopped; do not remove a serving database to apply this edit.
