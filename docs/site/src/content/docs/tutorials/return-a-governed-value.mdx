In about ten minutes you will ask the project from [Your first assertion](../first-evidence-assertion/)
which region a synthetic person lives in, and read `north` from a verified response. The project
lists every value the answer may take, so a Function cannot return any other.

  outcome="A verified residence-region assertion carrying one declared value."
  time="About 10 minutes"
  level="Local development with synthetic data"

/>

## Read the region's declared values

```sh test-cwd="first-evidence-assertion"
cd adult-status
```

In `evidence.yaml`, the `residence-region` assertion definition's `region` output is a
`controlled-category`: `values` lists every value it may carry.

```yaml title="evidence.yaml" test-excerpt="evidence.yaml"
outputs:
  region:
    concept: urn:example:concept:residence-region:v1
    type: controlled-category
    values:
    - north
    - south
```

One fixture case returns a value outside that list. Run the region fixtures with their trace:

```sh
evidencectl test . --target local-target.yaml --fixture fixtures/residence-region.yaml --explain
```

```text test-excerpt
"id": "negative-outside-controlled-values",
"observedResult": {
  "class": "service-unavailable"
},
"reasonCode": "output-refused",
```

Evidence Gateway refused that output.

## Read who may ask

The same definition sets a `grantCeiling`, the widest authority any grant may give for it:

```yaml title="evidence.yaml" test-excerpt="evidence.yaml"
purpose: residence-check
grantCeiling:
  authorities:
  - organizational
  actorKinds:
  - service
  valueOrigins:
  - request
  audiences:
  - urn:example:audience:standalone-app
```

`dev-authority.yaml` grants one exact request shape within it:

```yaml title="dev-authority.yaml" test-excerpt="dev-authority.yaml"
- definition: residence-region
  purpose: residence-check
  audienceFrom: authenticated-requester
  representations:
  - signed-jws
  subjectBinding: audience-scoped
  subjects:
  - role: subject
    selectorProfile: record-by-id
    valueOrigin: request
```

This grant belongs to the `standalone-service` access profile, the one `tutorial-client` holds.

## Start the source and Evidence Gateway

In another terminal, start the synthetic source from this directory:

```sh test-cwd="first-evidence-assertion/adult-status" test-background="http://127.0.0.1:8081/healthz"
python3 serve-source.py \
  --port 8081 \
  --token-file .generated/secrets/synthetic-source-token
```

Back in the first terminal, start Evidence Gateway:

```sh
evidencectl dev start . \
  --target local-target.yaml \
  --evidence-port 18080 \
  --issuer-port 8082
```

```text test-excerpt
Evidence ready at http://127.0.0.1:18080
```

## Request the region

```sh
evidencectl request prepare residence-region \
  --client tutorial-client \
  --purpose residence-check \
  --subject subject:record-id=adult \
  --name residence-region
```

```text test-expect
Prepared request: .evidence/requests/residence-region/request.json
Prepared verification context: .evidence/requests/residence-region/verification.json
Prepared authorization: .evidence/requests/residence-region/authorization.curl
```

Send the request, then verify the response before reading it:

```sh
curl --silent --show-error --fail-with-body \
  --config .evidence/requests/residence-region/authorization.curl \
  --request POST \
  --url http://127.0.0.1:18080/v1/evidence \
  --header 'Content-Type: application/json' \
  --header 'Accept: application/jose+json' \
  --data-binary @.evidence/requests/residence-region/request.json \
  --output residence-region.jws.json
evidencectl verify residence-region.jws.json \
  --context .evidence/requests/residence-region/verification.json \
  --output residence-region.verified.json
```

```text test-expect
VERIFIED
```

```sh
jq '.supportedValues' residence-region.verified.json
```

```json test-expect
[
  {
    "providesValueFor": "urn:example:concept:residence-region:v1",
    "value": "north"
  }
]
```

## Stop Evidence Gateway

```sh
evidencectl dev stop .
evidencectl dev clean .
```

```text test-expect
Local Evidence stopped
Removed stopped local Evidence state
```

Stop the source with `Ctrl+C` in its terminal. The next tutorial starts both again.
