Each line is one Registry Stack release, newest first, with a summary taken from its release
note and a link to the full note.
The release notes carry the breaking changes and upgrade steps.
Per-product detail is in the `CHANGELOG.md` of each product under
[`products/`](https://github.com/registrystack/registry-stack/tree/main/products) in the source
repository.

- [v0.48.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.48.0.md) (beta-60): Base Registry Engine (BReg) generates bounded Evidence sources, adds `changedAny` webhook conditions, and refuses derived values computed from incomplete source rows.
- [v0.47.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.47.0.md) (beta-59): `rstack dev` runs Base Registry Engine (BReg), Casework, Evidence, and Messaging projects on a workstation, replacing per-product development sessions.
- [v0.46.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.46.0.md) (beta-58): Releases publish the Adapter binaries, Rhai scripts run on a deterministic engine, and Registry Render seals documents with PAdES signatures.
- [v0.45.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.45.0.md) (beta-57): Evidence sources move into reviewed Adapter packs, and governed Adapter ingestion jobs deliver records to BReg or Registry Coordinator.
- [v0.44.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.44.0.md) (beta-56): Introduces `rstack` for a managed local installation and publishes the Registry Coordinator binaries, installer, and clients for the first time.
- [v0.43.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.43.0.md) (beta-55): Extends shared checks for authored display text and local identifiers, and BReg activates display-only successor packages as metadata updates.
- [v0.42.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.42.0.md) (beta-54): Starts a fresh state baseline for every stateful product, replaces BReg change requests with Proposals, and makes Casework review-only.
- [v0.41.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.41.0.md) (beta-53): Adds deferred Casework task grants and original-receipt reads, and raises the Node.js and Python client runtime floors.
- [v0.40.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.40.0.md) (beta-52): Establishes one configuration convention across the maintained products and publishes the compatibility promise that takes effect at 1.0.
- [v0.39.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.39.0.md) (beta-51): Removes Registry Relay, which v0.38.0 is the last release to carry, and BReg adds governed statistical datasets.
- [v0.38.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.38.0.md) (beta-50): BReg adds a subject-facing access log, Scheduling publishes `v1alpha2`, and Evidence can read assertions from another Evidence deployment.
- [v0.37.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.37.0.md) (beta-49): BReg holds delegated agents to a lower ceiling and records the agent behind a delegated request in its audit journal.
- [v0.36.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.36.0.md) (beta-48): Records BReg activations in a database ledger and makes BReg packages environment neutral. Casework and Scheduling activate with `plan` and `apply`.
- [v0.35.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.35.0.md) (beta-47): The supported upgrade bridge from v0.34.0. Every runtime moves to one shared `runtime.yaml` loader, package format, and audit writer.
- [v0.34.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.34.0.md) (beta-46): Adds consent-gated reads to BReg and lets one Casework source pair every change-request entity of a BReg registry. Closes lifecycle gaps in combined projects.
- [v0.33.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.33.0.md) (beta-45): Introduces Registry Scheduling, moves governed review into Casework, and adds durable ingestion, field encryption, and WebAssembly action handlers to BReg.
- [v0.32.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.32.0.md) (beta-44): Binds exchanged tokens to the assertion authority that issued their subject. BReg can re-check Evidence when it applies a governed request.
- [v0.31.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.31.0.md) (beta-43): Adds institutional contextual authorisation across Registry Casework, ThunderID, Evidence Gateway, and BReg, and retires Registry Mint.
- [v0.30.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.30.0.md) (beta-42): Introduces Registry Casework and its Rust, Node.js, and Python clients, and completes BReg client capability coverage.
- [v0.29.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.29.0.md) (beta-41): Adds governed request attachments, reviewer explanations, and local event inspection to BReg, with attachment APIs in the clients.
- [v0.28.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.28.0.md) (beta-40): Adds governed BReg actions with optional verified Evidence calls, field integrity and membership reads, and guided starter and source workflows.
- [v0.27.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.27.0.md) (beta-39): Adds explicit BReg access configuration and BReg-to-Evidence authoring workflows, with breaking BReg configuration and problem-response changes.
- [v0.26.1](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.26.1.md) (beta-38): Publishes the first unified Node.js and Python clients, with runtime APIs and configuration unchanged from v0.26.0.
- [v0.26.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.26.0.md) (beta-37): Introduces Base Registry Engine, a configuration-compiled PostgreSQL system of record, and the Registry Record v1 response profile.
- [v0.25.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.25.0.md) (beta-36): Makes an Evidence fixture run diagnosable by a program, with one breaking change in adopter tooling.
- [v0.24.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.24.0.md) (beta-35): Publishes Registry Discovery as a released `discovery` container image and Linux binary for the first time.
- [v0.23.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.23.0.md) (beta-34): Adds Registry Discovery as a curated read-only index of public service descriptions, and a progressive Evidence client API.
- [v0.22.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.22.0.md) (beta-33): Adds explicit container-deployment contracts, managed OAuth-client compatibility for Registry Mint, and client package distribution through npm and PyPI.
- [v0.21.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.21.0.md) (beta-32): Adds official, digest-pinned OCI images for Evidence Gateway and Registry Mint alongside the Relay image.
- [v0.20.1](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.20.1.md) (beta-31): Fixes forward from v0.20.0 with support for governed HTTP sources that intentionally collapse unresolved lookup outcomes.
- [v0.20.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.20.0.md) (beta-30): Completes the move to Relay V2 and Evidence, publishes a versioned documentation archive, and removes Relay V1 and `registryctl` source.
- [v0.19.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.19.0.md) (beta-29): Introduces Relay V2 as the supported read-only registry API and adds bounded multi-subject Evidence request batching.
- [v0.18.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.18.0.md) (beta-28): Adds holder-bound Evidence credentials, an OID4VCI wallet-delivery adapter, reviewed SQLite extraction, and bounded multi-stage source acquisition.
- [v0.17.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.17.0.md) (beta-27): Adds Evidence as the maintained minimum-disclosure assertion product, retires Registry Notary, and tightens Registry Relay attribute release.
- [v0.16.3](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.16.3.md) (beta-26): Carries the v0.16.2 product behaviour unchanged and simplifies Beta publication and recovery.
- [v0.16.2](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.16.2.md) (beta-25): Repairs draft release discovery in the publication workflow. Its publication stopped after staging an unpublished draft, as the v0.16.3 note records.
- [v0.16.1](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.16.1.md) (beta-24): Repairs the release workflow startup path. Its publication stopped after creating an unpublished empty draft, as the v0.16.2 note records.
- [v0.16.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.16.0.md) (beta-23): Completes the maintained spreadsheet and HTTP adopter journeys. Its release workflow failed before any public write, as the v0.16.1 note records.
- [v0.15.2](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.15.2.md) (beta-22): Carries the v0.15.1 product behaviour unchanged and repairs the remaining release publication blockers.
- [v0.15.1](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.15.1.md) (beta-21): Repairs the release publication path. It stopped before creating a GitHub Release, as the v0.15.2 note records.
- [v0.15.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.15.0.md) (beta-20): Focuses on first-country authoring and local onboarding. Its release workflow stopped before any public write, as the v0.15.1 note records.
- [v0.13.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.13.0.md) (beta-17): Tightens the Relay and Notary evidence boundary and replaces the deployment-waiver metadata contract.
- [v0.12.2](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.12.2.md) (beta-16): Carries the beta-14 product scope with release-build, dependency-security, release-gate, and Notary transport fixes only.
- [v0.12.1](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.12.1.md) (beta-15): Fixes forward after v0.12.0 stopped at the image advisory gate. Its own publication stopped at that gate, as the v0.12.2 note records.

Its publication stopped at the image advisory gate, as the v0.12.1 note records.
- [v0.11.0](https://github.com/registrystack/registry-stack/blob/main/release/notes/v0.11.0.md) (beta-13): Credential issuance accepts only fresh, non-delegated stored evaluations, and claim evaluation formats get one closed contract.
