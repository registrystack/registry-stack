Evidence answers one bounded question about one subject and signs the answer,
without releasing the record the answer came from. A relying service asks
whether a person meets a condition and receives a signed assertion carrying
the answer, not the row that settled it.

The quickest way to see that boundary is the
[first Evidence assertion tutorial](../../tutorials/first-evidence-assertion/). It starts with an
OpenAPI description, adds one question and derivation, sends a real HTTP request, and verifies the
signed response before showing its answer.

## Four questions, none of them privileged

Adult status, residence region, professional licence status, and legal-parent
relationship are coequal acceptance definitions. None is a built-in type, a
special route, or a first phase that the others follow. Whichever one your
institution needs, you author it the same way.

An acceptance definition is a reviewed artifact, not code you ship. Evidence
compiles the definition at startup from an immutable bundle, and refuses to
start if the definition does not compile.

## The current path

- [Get your first Evidence assertion](../../tutorials/first-evidence-assertion/)
  goes from OpenAPI to an authored adult-status question, a real `curl`, strict
  verification, and a minimized audit view using synthetic local data.
- [Evaluate Evidence](../evaluate-evidence/) explains the complete deployment
  layout and its runtime dependencies.
- [Configure Evidence](../../configure/evidence/) documents the governed
  bundle, runtime file, authorization, source, signing, and audit contracts. It
  also records exactly what `evidencectl new` does and does not generate.
- [Move to production signing](../../tutorials/move-evidence-to-production-signing/)
  applies after an operator already has a complete deployment project.

The first tutorial is intentionally local. It demonstrates the complete assertion boundary without
presenting its disposable keys, loopback source, or Registry Mint setup as a production deployment.

## If you are deciding rather than building

- [When Registry Stack fits](../when-to-use/) settles which door you want:
  Registry Relay to read specific data, Evidence to learn only a fact.
- [Evaluate Evidence](../evaluate-evidence/) is the cost accounting: what
  Evidence needs to start, what it does not depend on, how it deploys today,
  and what operating it demands.
- [Evidence security model](../../security/evidence/) traces the runtime rules
  to the invariant matrix and the tests that hold them.
