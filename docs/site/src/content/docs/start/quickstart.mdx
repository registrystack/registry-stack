Use the two local tutorials for the Registry Stack v0.14 beginner path. Start
with Registry Relay, then continue to a live Registry Notary claim.

## Run your first registry API

[Run your first registry API](../../tutorials/publish-spreadsheet-secured-registry-api/)
installs Registryctl from release assets, starts Registry Relay over maintained
synthetic data, and checks denied and allowed requests.

## Verify a live claim

[Verify a live registry-backed claim](../../tutorials/verify-claim-registry-api/)
continues from the first API to a running Registry Notary service and checks
match, no-match, and denied requests.

## Connect your data

[Use your own spreadsheet](../../tutorials/use-your-spreadsheet/) replaces the
sample workbook with one reviewed non-personal workbook after the local first
run works.

## About older quickstart links

The former hosted quickstart and Solmara Lab tutorials used different
deployment topologies. They are not the supported v0.14 beginner path, and the
local tutorials are not equivalent replacements for those retired flows. Old
links land on this chooser so you can select a current local task without
mistaking it for hosted onboarding.
