Before handing a retained Registry Stack product to operators, use that product's deployment guide
to record its configuration revision, external dependencies, credentials, audit destination,
health checks, backup scope, upgrade procedure, and rollback boundary.

Continue with the [operations overview](advanced/) and the product-specific pages linked from its
documentation section.
