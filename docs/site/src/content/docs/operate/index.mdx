Before handing a retained Registry Stack product to operators, use that product's deployment guide
to record its configuration revision, external dependencies, credentials, audit destination,
health checks, backup scope, upgrade procedure, and rollback boundary.

Continue with the [operations overview](advanced/) and the product-specific pages linked from its
documentation section.

Use the [retention map](retention-and-persistent-state/#find-the-owning-retention-control) to
locate each product's data and audit settings. Check the existing
[container exposure example](breg/#serve-the-container-image) before binding a container listener,
and verify downloaded assets with the release's
[release verification procedure](https://github.com/registrystack/registry-stack/blob/main/release/VERIFY.md).
