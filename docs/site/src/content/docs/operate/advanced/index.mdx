## Source adaptation

- [Operate bounded Script workers and protocol helpers](operate-script-workers/)

The public Relay lane and the consultation Relay lane activate separate product bundles, each
with its own anchor, identity, and anti-rollback state.
Neither serving workload depends on the other; only the consultation lane's state actions wait on
a healthy PostgreSQL.
Admit traffic to a lane only after that lane's product boundary passes.
This sequence is compatible staged admission, not atomic project activation.
