# Shared Evidence project

Place the ordinary editable EvidenceProject here: selectors, fixed
Sources, named Functions, schemas, AssertionDefinitions, derivations, codelists, and synthetic
fixtures. Keep environment identities, endpoints, public service keys, Transit
versions, runtime paths, and secret references in the complete environment
targets beside this directory. The template target and authority use project
ID `example-evidence`, definition `record-status`, role `subject` and selector
profile `record-reference-v1`. Match these to the reviewed project and add its
required Source connection or extract bindings before checking or packaging.

Application developers work here through `evidencectl init` and `evidencectl
dev`. Deployment operators select an environment target only when building and
handing off a candidate.
