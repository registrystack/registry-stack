# Registry Stack v0.15.2

Registry Stack v0.15.2 is the beta-22 fix-forward release. It carries the
v0.15.1 candidate product behavior unchanged and repairs the remaining release
publication blockers.

The immutable v0.15.0 and v0.15.1 tags remain failed-train evidence. v0.15.0
stopped before any public write. v0.15.1 promoted its public image tags, then
stopped before creating a GitHub Release because capsule generation did not
recognize that a verified candidate image and its promoted public image retain
the same digest under intentionally different repository names.

## Publication fixes

- Release capsule generation accepts only the exact
  `registry-notary-candidate` to `registry-notary` and
  `registry-relay-candidate` to `registry-relay` repository transitions when
  the digest is unchanged. An unrelated repository with the same digest
  remains rejected.
- Promotion telemetry is observational and no longer blocks publication.
  Candidate measurement validation accepts the nonempty receipt-bound
  measurement inventory instead of duplicating an obsolete fixed artifact
  count.
- The tag workflow verifies the candidate receipt, artifacts, attestations,
  image digests, documentation archive, SBOMs, vulnerability reports, release
  capsule, and checksums before creating the GitHub Release.

## Product scope

- Registry Relay, Registry Notary, Registryctl, Registry Manifest, and Registry
  Platform have no user-visible changes relative to v0.15.1.
- Crosswalk remains pinned at
  `1d44ec735fdc8a7c719264b339574371e8330337`.
- Solmara Lab repinning, hosted publication, external OpenID, OpenCRVS, DHIS2,
  wallet, verifier, and country-acceptance evidence remain separate gates.
  This source release does not claim those results.
