# Registry Stack v0.16.2

Registry Stack v0.16.2 is the beta-25 fix-forward release. It carries the
v0.16.0 and v0.16.1 candidate product behavior unchanged and repairs draft
release discovery in the publication workflow.

The immutable v0.16.0 and v0.16.1 tags remain failed-train evidence. v0.16.0
failed before any job or public write. v0.16.1 stopped after creating an
unpublished empty draft GitHub Release. Neither train published final images,
assets, or documentation. Install only v0.16.2.

## Product scope

- Registry Relay, Registry Notary, Registryctl, Registry Manifest, and Registry
  Platform have no user-visible changes relative to the v0.16.0 and v0.16.1
  candidates.
- Crosswalk remains pinned at
  `1d44ec735fdc8a7c719264b339574371e8330337`.

## Upgrade requirements

- When upgrading from v0.15.2 or earlier, regenerate projects with Registryctl
  v0.16.2 and recreate reviewed 1.0 acceptance lineage. Do not edit or reset
  governed state in place.
- Quiesce consultations and cleanly re-bootstrap the pre-1.0 Relay state plane
  before upgrading. Do not run older and v0.16.2 Relay binaries against one
  state plane.
- Stop Notary writers, take a verified backup, then run the v0.16.2 `state
  install` and `state doctor` commands before admitting traffic. Older or
  drifted catalogs require a sequential upgrade, a matching backup and binary,
  or a fresh installation.

## Release boundaries

- Draft release discovery is bound to the GitHub release identifier before
  publication continues. This is a release-only fix and does not change
  product behavior.
- Hosted publication, Solmara repinning, external OpenID, OpenCRVS, DHIS2,
  wallet, verifier, and country-acceptance evidence remain separate gates.
  This source release does not claim those results.
