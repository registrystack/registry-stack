# Registry Stack v0.21.0

Registry Stack v0.21.0 is the beta-32 release. It adds official, digest-pinned
OCI images for Evidence Gateway and Registry Mint alongside the existing Relay
image. Runtime APIs, authored contracts, and configuration formats are
unchanged from v0.20.1.

## Official runtime images

- Evidence Gateway is published as `ghcr.io/registrystack/evidence:v0.21.0`.
- Registry Mint is published as `ghcr.io/registrystack/mint:v0.21.0`.
- Registry Relay V2 remains available as
  `ghcr.io/registrystack/relay:v0.21.0`.
- All three images run as a fixed non-root user, use a minimal distroless
  runtime, and contain only the release binary and license. Configuration,
  governed packages, keys, secrets, and audit storage remain operator-mounted.
- Release publication promotes the three exact scanned candidate manifests.
  Each final tag is verified against its recorded digest rather than rebuilt.

## Configuration and compatibility

- Evidence reads the operator-mounted runtime configuration selected by
  `REGISTRY_EVIDENCE_RUNTIME`, defaulting to
  `/etc/registry-evidence/runtime.yaml`.
- Mint reads the operator-mounted configuration selected by `MINT_CONFIG`,
  defaulting to `/etc/registry-mint/config.yaml`.
- Relay reads the operator-mounted runtime configuration selected by its
  `--runtime` argument, which defaults in the image to
  `/etc/relay/runtime.yaml`.
- The repository's top-level `docker/` definitions remain local source-build
  images. Official release images use the reviewed definitions under
  `release/docker/`.
- Existing v0.20.1 binaries and the Relay runtime contract remain compatible.
  This minor release reflects the new supported public distribution surfaces,
  not a service behavior change.

## Release boundaries

- All Registry Stack artifacts remain version-aligned at v0.21.0. Binaries,
  installers, client packages, documentation, checksums, Sigstore evidence,
  and the candidate manifest are published through the standard release
  closure.
- Hosted deployments, external conformance, and adopter-specific rollout
  exercises remain outside this release's critical path.
