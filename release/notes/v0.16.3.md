# Registry Stack v0.16.3

Registry Stack v0.16.3 is the beta-26 stabilization release. It carries the
v0.16.2 candidate product behavior unchanged and simplifies Beta publication
and recovery.

The immutable v0.16.0, v0.16.1, and v0.16.2 tags remain failed-train evidence.
v0.16.2 stopped after staging an unpublished draft and before public image
promotion. No train published final images, assets, or documentation. Install
only v0.16.3.

## Product scope

- Registry Relay, Registry Notary, Registryctl, Registry Manifest, and Registry
  Platform have no user-visible changes relative to the v0.16.2 candidate.
- Crosswalk remains pinned at
  `1d44ec735fdc8a7c719264b339574371e8330337`.

## Upgrade requirements

- When upgrading from v0.15.2 or earlier, regenerate projects with Registryctl
  v0.16.3 and recreate reviewed 1.0 acceptance lineage. Do not edit or reset
  governed state in place.
- Quiesce consultations and cleanly re-bootstrap the pre-1.0 Relay state plane
  before upgrading. Do not run older and v0.16.3 Relay binaries against one
  state plane.
- Stop Notary writers, take a verified backup, then run the v0.16.3 `state
  install` and `state doctor` commands before admitting traffic. Older or
  drifted catalogs require a sequential upgrade, a matching backup and binary,
  or a fresh installation.

## Release boundaries

- Beta publication runs from protected `main`, uses one exact candidate, and
  reconciles matching draft assets and image digests on retry. It does not
  overwrite incompatible public state.
- The Beta workflow accepts only `v0.x.y` releases. The 1.0 release contract is
  outside this train.
- Hosted publication, Solmara repinning, external OpenID, OpenCRVS, DHIS2,
  wallet, verifier, and country-acceptance evidence remain separate gates.
  This source release does not claim those results.
