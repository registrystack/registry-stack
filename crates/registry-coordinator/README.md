# Registry Coordinator

Registry Coordinator executes reviewed finite, acyclic workflow packages using
PostgreSQL, bounded pure Rhai functions and maintained Registry Stack clients.
It serves authenticated institutional admissions, caller-owned progress and
explicit operator recovery. Receiving products retain ownership and authority
for every external effect.

`coordinatorctl` checks and tests projects offline, builds immutable packages,
applies PostgreSQL activation and operates the authenticated API. `coordinator`
serves the activated package and worker without migrating at startup.

See the [product contract](../../products/coordinator/PILOT-CONTRACT.md),
[deployment runbook](../../products/coordinator/DEPLOYMENT.md), and
[maintained projects](../../products/coordinator/README.md). This service supports
controlled institutional pilots; public release and production rollout are
outside the current milestone.
